# ISSUES — audit of the existing pipeline (bugs, leakage, protocol threats)

Status values: `OPEN` · `FIXED (run_id)` · `WONTFIX (reason)`. Every issue that can bias a reported number
must name which runs it affects. When an issue is fixed, re-run the affected experiments and mark the old
runs `invalid` with `automation/log_run.py invalidate`.
